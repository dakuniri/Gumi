# セキュリティと安全性

## Electron

- 全ウィンドウ: `contextIsolation: true` / `nodeIntegration: false` / `sandbox: true` / `webviewTag: false`
- Preload は許可リストのチャネルだけを `window.gumi` として公開 (Node.js API は公開しない)
- IPC: 送信元フレームの URL がアプリ自身のページか確認し、引数を zod で検証。例外はメッセージのみ返す
- CSP: 本番は `script-src 'self'` などの厳格な CSP を index.html に埋め込み
- 新規ウィンドウ・外部ナビゲーション・リダイレクト・webview を禁止。Renderer の権限要求はすべて拒否
- Renderer からの外部ネットワークは遮断 (AI API への通信は Main Process のみ)。ローカルファイルもアプリ自身の画面ファイル (`dist/`) 以外は読み込ませない

## API キー

- Electron `safeStorage` (Windows は DPAPI、macOS はキーチェーン) で暗号化して `secrets.json` に保存。暗号化が使えない環境では保存を拒否。ファイル自体も本人だけが読める権限で作成
- Renderer には「設定済みかどうか」だけを渡し、キー自体は渡さない
- API エラーメッセージからキー文字列を除去
- リモートのエンドポイントは https のみ (http はローカルホストだけ許可)

## 操作の権限制御

- AI はコードを実行できず、型付きツールのみ呼び出せます (未知のツール・不正な引数は拒否)
- カテゴリごとに 許可 / 毎回確認 / 禁止 を設定。禁止カテゴリのツールは AI に提示もしません
- 確認ポリシー (高リスクのみ / 中リスク以上 / すべて)。次は常に確認:
  - ファイル削除 (ごみ箱へ移動のみ。完全削除はできません)、既存ファイルの上書き
  - シェル・管理ツール・インストーラーの起動 (Windows: コマンドプロンプト・PowerShell・レジストリエディタなど / macOS: ターミナル・スクリプトエディタ・ディスクユーティリティ・キーチェーンアクセス・.pkg など)
  - 影響の大きいショートカット (Windows: `Win+R` `Alt+F4` `Shift+Delete` など / macOS: `Cmd+Q` `Cmd+Delete` など)
  - AI 自身の `request_confirmation` (送信・購入・個人情報の送信・アプリ内の削除・インストール・重要な設定変更・サインインなど、UI 経由の取り消せない操作の前に必須とプロンプトで指示)
- 送信不可のキー操作: `Ctrl+Alt+Del`・`Win+L`、macOS の画面ロック (`Ctrl+Cmd+Q`)・ログアウト (`Cmd+Shift+Q`)・強制終了 (`Cmd+Option+Esc`)・ゴミ箱を空にする操作、Gumi の緊急停止 / 一時停止ショートカット
- 操作できない場所:
  - Windows: システム領域 (Windows, Program Files, ProgramData 等)・ドライブのルート・ネットワークパス
  - macOS: `/System` `/Library` `/Applications` `/usr` `/private` などのシステム領域、`~/Library` (キーチェーンやアプリのデータ)、ルートやボリュームそのもの
  - 両方: Gumi 自身のデータとインストール先
- Gumi 自身のウィンドウは操作・列挙の対象外
- URL は http(s) のみ。アプリ起動で使える URI スキームは OS 標準のものに限定 (Windows: `ms-settings:` など / macOS: `x-apple.systempreferences:` など)
- Web 検索のページ取得は公開サイトのみ。localhost・プライベート IP・リンクローカル (169.254.x.x など) は DNS 解決後の IP でも確認して拒否し、リダイレクト先も毎回検証する。本文取得は 1 回の検索につき最大 3 サイト

## ユーザーが常に止められること

- 作業中は円の上に出る「一時停止」「停止」ボタン
- グローバルショートカット (既定: 緊急停止 `Ctrl+Alt+Esc`、一時停止/再開 `Ctrl+Alt+P`)
- AI がマウス / キーボードを操作している最中にユーザーがマウス / キーボードを使うと自動で一時停止 (AI が考えている間は止めない。設定で無効化可)。OS の「最後に入力があった時刻」と、Gumi が入力を送った時刻を比べて判定する
- 停止時は API 呼び出しを中断し、押下中のキー・マウスボタンを解放
- タスクトレイに常駐アイコンを表示し、状態をツールチップに表示 (秘密裏に動作しない)
- タスクはユーザーの明示的な指示でのみ開始

## macOS の許可

- アクセシビリティ (マウス・キーボード操作と UI 要素の取得) と画面収録 (スクリーンショット) は、ユーザーがシステム設定でオンにしたときだけ使える。Gumi が勝手にオンにすることはできない
- 指示を送ったときに許可が足りなければ、タスクを始めずに理由を表示し、システム設定の該当ページへ案内する

## 送信する情報

Gumi が通信するのは、設定した AI プロバイダーと、Web 検索ツールの DuckDuckGo だけです。利用状況の収集や自動アップデートの確認などは行いません。


- 指示文、スクリーンショット (縮小 JPEG)、ウィンドウタイトル、UI 要素の名前と位置、操作結果
- Web 検索を使った場合は、検索語が DuckDuckGo に送信される (権限設定で「毎回確認」「禁止」にできる)
- 送信内容の概要 (文字数・画像枚数・送信先) をタスクトレイのアイコンのツールチップに表示
- スクリーンショット共有範囲: カーソルのあるディスプレイ / メインディスプレイ / アクティブウィンドウのみ
- タイトルに機密キーワード (既定: パスワード, 1Password, KeePass など) を含むウィンドウが表示中は画像を送信しない
- クリップボード・ファイル・UI 要素の値に含まれる API キー・トークン・カード番号 (Luhn 検証)・パスワード表記をマスク
- 履歴にスクリーンショットは保存しない。履歴保存を無効にするとファイルも削除
