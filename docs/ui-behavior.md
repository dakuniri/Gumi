# UI の振る舞い

## 円 (Gumi)

- 白 (黒の縁) / 黒 (白の縁) / 亜夢 (緑 #279634 に白の記号) の小さな円。既定 36px (20〜96px)
- 透明・枠なしのウィンドウ。円と小さな円の上だけマウスを受け付け、それ以外のクリックは背後のアプリへ透過 (Main がカーソル位置から判定)
- 既定で最前面。画面共有や通常のスクリーンショットには映る
- AI が画面を撮影する間だけ OS のキャプチャ除外 (Windows: `SetWindowDisplayAffinity` / macOS: ウィンドウの共有設定) を有効にして、AI の撮影には写らないようにする。透明にはしないので画面上では消えず、ちらつかない (撮影中の一瞬だけ画面共有の相手側には写らないことがある。設定で無効化可)
- macOS: Dock にアイコンを出さず、すべてのデスクトップ (操作スペース) とフルスクリーンのアプリの上にも表示する

## ホバーで出る 2 つの小さな円

| | 動作 |
|---|---|
| 歯車の円 | 設定画面を開く。カーソルを合わせると歯車が回る |
| 半分塗りの円 | 色を切り替える (白 / 黒)。円・入力欄・設定画面すべてに即時反映し保存。亜夢のときに押すと白に戻る |

- カーソルを円に合わせて 120ms 後に、円の中心から**上**へ順番に飛び出す (画面上端で余白が無い場合のみ下)。閉じるときは円の中へ戻る
- 円・小さな円・その間の通路から離れて 400ms で閉じる (移動中に閉じない)
- ドラッグ中・入力中・作業中は出さない。小さな円を押した後は、カーソルが一度離れるまで再表示しない

## 入力欄と作業中のボタン

```text
入力中:   [停止] (        入力欄        )(円)
作業中:            [一時停止] [停止]
                         (円)
```

- 円をクリックすると、円の左に横長の入力欄が円から伸び出るように現れ、その左に停止ボタンが出る (円が画面の左端で余白が無いときは左右反転して右側)
- 入力して Enter で実行。日本語変換の確定の Enter では送信しない。Esc か停止ボタンで入力をやめる。何も入力せずに他の場所をクリックしても閉じる
- 実行すると、入力欄は幅が縮みながら円の中へ吸い込まれるように収納され、停止ボタンは円の上へ移動、その左に一時停止ボタンが現れる (画面上端で余白が無いときは円の下)
- 一時停止ボタンは押すと再開ボタンに変わる。停止ボタンは即時停止 (押されたままのキー・ボタンも解放)
- 作業が終わるとボタンは円の中へ戻る
- 自動の一時停止 (あなたの操作を検出) は、AI が実際にマウス / キーボードを操作している間だけ。一時停止すると一時停止ボタンが「再開」に変わる
- 送信できなかった場合 (API キー未設定など) は入力欄が揺れて、理由を下に表示する

## 色

| 色 | 円 | 入力欄・小さな円・ボタン・設定画面 |
|---|---|---|
| 白 | 白に黒の縁と記号 | 白の配色 |
| 黒 | 黒に白の縁と記号 | 黒の配色 |
| 亜夢 | 緑 (#279634) に白の記号 | 「亜夢の画面の色」で白か黒の配色を選ぶ |

亜夢は設定画面 (外観) からだけ選べます。

## AI のカーソル

- AI がマウスを動かしている間、その位置に「<」の形のカーソルを表示する。とがった先端は左上を向き、先端がクリック位置
- 色は設定に合わせる (白: 黒い塗りに白い縁、黒: 白い塗りに黒い縁、亜夢: 緑の塗りに、選んだ画面の色の縁)
- クリックを透過する小さな透明ウィンドウで、AI のクリックを邪魔しない。AI の撮影には写らない (画面上では消えない)。作業が終わると消える
- 設定 (外観) で表示しないこともできる

## クリック / ドラッグ

- クリック: 入力欄を開閉 (作業中は何もしない。一時停止・停止は円の上のボタン)
- ドラッグ: 4px 以上動かすと移動。離した位置で画面内に収め、端から 28px 以内なら吸着。位置 (中心とディスプレイ) を保存し、再起動時に復元
- 画面内に収めるときは、円だけでなく作業中の一時停止・停止ボタン、上に出る小さな円、状態のリングまで画面の端で切れない位置にする (`orbExtent`)
- ディスプレイの追加・削除・解像度変更時と、起動直後 (表示前と 3 秒後) にも画面内へ戻す

## 作業の結果

- 作業が終わると、円の横 (入力欄の位置) に結果の吹き出しを出す。完了なら AI のまとめ (検索結果など)、失敗ならその理由 (例: AI サービスの残高不足)
- 吹き出しをクリックすると閉じる。円をクリックして次の指示を入力し始めても閉じる。停止したときは出さない

## 承認・質問

- 承認が必要な操作や AI からの質問があると、別の画面は開かずに、円の横 (入力欄の位置) に出す
- 承認: 操作の内容と「許可」「拒否」ボタン。内容の上に理由を小さく表示 (全文はマウスを重ねると出る)
- 質問: 質問文を上に小さく表示し、入力欄で回答して Enter
- 作業中の一時停止・停止ボタンは円の上にそのまま出ている
- 会話・操作のログと過去のタスクは設定画面の「履歴」で見る

## 状態の表現 (白黒のみ、動きで区別)

状態は `resolveExpression` (純粋関数) だけで決定し、矛盾する表現が同時に出ないようにしています。

| 状態 | 表現 |
|---|---|
| 通常 / 待機 | 静止 |
| ホバー | 少し大きくなる |
| 考え中 | 円の中に「?」(左右に揺れる) + 周囲のリングが点滅 |
| 検索中 (Web 検索) | 円の中に虫眼鏡 (左右に動く) + 周囲のリングが点滅 |
| PC 操作中 | 円の中に「・・・」(順番に跳ねる) + 周囲の弧が回転 |
| 承認・回答待ち / 一時停止 | 破線のリングがゆっくり回転 |
| 完了 | 円の中にチェックマークが描かれる (約 6 秒) + リングが広がって消える |
| 失敗・エラー | 左右に揺れ、太いリング |
| スリープ (操作なしが一定時間) | 薄くなりゆっくり呼吸。カーソルを合わせると戻る |
| ドラッグ中 | 少し大きくなる |

スリープは表示上の待機状態で、PC をスリープさせることはありません。タスク実行中・承認待ちの間はスリープしません。
